# Unflare | Experimental Sandbox & Portfolio

**Unflare** es mi espacio de pruebas personal (*sandbox*). Este repositorio está diseñado como un entorno de experimentación web donde pruebo componentes, maquetaciones responsivas, animaciones y nuevas tecnologías antes de implementarlas en proyectos de producción (como *Nature Future*).

## ¿Qué se prueba en este espacio?
* **Diseño Responsivo:** Pruebas de maquetación *mobile-first* y adaptabilidad en diferentes tamaños de pantalla.
* **Componentes UI/UX:** Experimentación con efectos visuales, estructuras de tarjetas, tipografías y paletas de colores.
* **Optimización de Código:** Pruebas de rendimiento y limpieza en JavaScript, HTML y CSS antes de integrarlos al flujo de trabajo principal.

## Stack Tecnológico
Las tecnologías principales utilizadas en este sandbox incluyen:
* **HTML5** / **CSS3** (Estructuras y estilos modernos)
* **JavaScript (ES6+)** (Lógica interactiva y pruebas de scripts)
* **Responsive Design** (Adaptabilidad multidispositivo)
